These SMS terms apply to text messages from Impulse, a program of Savannah Afsahi (sole proprietor).

Program

Impulse is a private personal-assistant text messaging program sent from (650) 532-7465. It sends reminders, calendar updates, replies to the recipient's own texts, and outbound approval requests (with a 4-digit reference number) before errands are completed. It has a single recipient, the operator.

How to opt in

Text START to (650) 532-7465 to receive Impulse messages. You will receive: "Impulse: You're set up to get reminders and assistant replies. Msg frequency varies. Msg & data rates may apply. Reply HELP for help, STOP to opt out."
